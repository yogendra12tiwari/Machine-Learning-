#  Exploratory Data Analysis (EDA)

Exploratory Data Analysis (EDA) is the process of understanding, cleaning,
analyzing, and visualizing a dataset before applying Machine Learning algorithms.

The main goal of EDA is to understand:

- What data we have
- How the data is structured
- Whether the data contains errors
- Missing values
- Duplicate values
- Outliers
- Data distributions
- Relationships between features
- Important patterns and trends
- Which preprocessing steps are required before Machine Learning

---

# Goals of EDA

The main objectives of EDA are:

1. Understand the dataset
2. Understand individual features
3. Identify data types
4. Find missing values
5. Find duplicate values
6. Detect incorrect or invalid values
7. Understand numerical distributions
8. Understand categorical distributions
9. Detect outliers
10. Find relationships between variables
11. Identify correlations
12. Find important patterns
13. Identify unnecessary features
14. Prepare the dataset for Feature Engineering
15. Prepare the dataset for Machine Learning
